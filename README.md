# Doors-OS-V1
🖥️ Doors OS V10.0™

Doors OS V10.0™ is a browser-based operating system simulation inspired by classic desktop operating systems.

The project recreates the experience of using a simple desktop environment inside a web browser. It includes a virtual file system, applications, draggable windows, a taskbar, Start menu, terminal commands, and other simulated system utilities.

🎯 What is Doors OS?

Doors OS was created as a web development project to experiment with building an interactive desktop-like environment using standard web technologies.

Instead of being a real operating system, Doors OS simulates common operating-system concepts through HTML, CSS, and JavaScript.

The goal is to make the browser feel more like a small fictional computer environment where users can open applications, move windows around, navigate virtual folders, and interact with simulated system tools.

✨ Features

🖥️ Desktop Environment

- Desktop-style operating system interface
- Start menu
- Dynamic taskbar
- Draggable application windows
- Simulated shutdown screen
- Retro-inspired desktop design

📁 My Computer

A simulated file-system interface containing a virtual "C:\" drive with folders such as:

C:\Doors
C:\Program Files
C:\Users
C:\Documents

These folders are simulated and do not access the real files on the user's computer.

🧮 Calculator

The built-in calculator supports:

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Delete
- Clear
- Dark/light theme switching

🛡️ Doors Anti Virus v1.0

A fictional antivirus application that simulates a system scan.

It includes:

- Animated scan progress
- Files scanned counter
- Simulated threat detection
- Randomized scan results
- Last scan timestamp
- Real-time protection status
- Scan completion notifications

The antivirus is intentionally a simulation and does not scan the user's actual computer.

💻 Terminal

Doors OS includes a terminal-style command interface.

Available commands include:

help
clear
about
date
echo [text]
color [color]

📢 StartApp SDK

The project also integrates the StartApp SDK for advertisement functionality.

🧰 Technologies

Doors OS is built with standard front-end web technologies:

- HTML5 — Page structure and application interfaces
- CSS3 — Desktop layout, styling, animations, and window design
- JavaScript — Applications, interactions, window behavior, simulated system logic, and terminal commands
- Font Awesome — Interface icons
- StartApp SDK — Advertisement integration

No build system or framework is required to run the project.

⚙️ How It Works

Doors OS uses JavaScript to control the behavior of the simulated operating system.

For example, when an application is opened, JavaScript creates or displays its interface and connects the required interactions. Window movement, taskbar behavior, calculator operations, terminal commands, simulated scans, and other interactions are handled in the browser.

The virtual file system is also part of the simulation. Its folders and files are represented by the web application rather than being created on the user's actual computer.

🛠️ Development

The project was developed as an ongoing experiment in interactive web development.

During development, I focused on building the desktop environment first and then adding individual applications and system features. Each application was implemented as part of the same browser-based environment so that it could interact with the desktop, windows, and taskbar.

The project also gave me practical experience with:

- DOM manipulation
- JavaScript event handling
- CSS layouts and animations
- Draggable interfaces
- Application state
- Interactive UI design
- Building multiple applications inside one web interface

The project is intentionally built with HTML, CSS, and JavaScript rather than using a large framework, making the individual parts easier to understand and modify.

🖱️ Running the Project

Doors OS does not require installation, dependencies, or a build process.
