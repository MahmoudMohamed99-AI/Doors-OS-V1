# Doors OS V10.0

Doors OS is a small web project where I tried to recreate the feel of using a desktop operating system inside a browser. The interface is inspired by Windows, but everything runs as a web page.

I built it to experiment with HTML, CSS, and JavaScript while making something interactive instead of just a static website.

## What can you do?

- **My Computer:** Open a simulated C: drive and browse virtual folders.
- **Window management:** Open and close app windows, drag them around, and access them again from the taskbar.
- **Start Menu:** Use one menu to access the available apps and system options.
- **Terminal:** Try commands like `help`, `clear`, `about`, `date`, `echo`, and `color`.
- **Calculator:** Perform basic arithmetic, clear the input, delete characters, and switch between dark and light themes.
- **Doors Anti Virus:** Run a simulated scan with a progress bar, scan counters, a last-scan time, and a completion notification.
- **Settings:** Open a placeholder settings window.
- **Shutdown:** Display a simulated shutdown screen.

## How to run it

Open this link : https://mahmoudmohamed99-ai.github.io/Doors-OS-V1/

## How it works

The interface is built with HTML and styled with CSS. JavaScript handles the interactive parts, including opening windows, updating the taskbar, processing terminal commands, and running the calculator.

The file explorer is a simulated folder structure rather than access to the computer's real files.

The Anti Virus app is also a simulation. Its scan progress and threat counts are generated for demonstration purposes; it does not scan files or protect the device.
